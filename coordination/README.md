## Single-writer rules

1. Read the other task's status before starting a new integration-sensitive change. Update your own status with current work, changed files, checks and any handoff needed.
2. Edit only owned files. Propose a cross-owner change in your status note, then message its owner. The owner makes the change or explicitly hands over ownership for a defined edit.
3. Root dependencies and configuration have one owner: the canvas task. Agent development uses its separate `agent/package.json` and lockfile so simultaneous installs cannot overwrite the root lockfile.
4. Do not build a second canvas, renderer, scene store, timer engine or sensor pipeline under `agent/`. Agent tests may use a small in-memory port mock for tool behavior, clearly labeled as test support rather than a simulator.
5. Do not start a second copy of the main app, take over a port, close a running app, or alter `.local-data/` without coordinating with the canvas task. Agent checks should run independently.
6. Automatically commit/push completed, appropriately tested work under the standing workflow in [AGENTS.md](../AGENTS.md). Stage only explicitly reviewed owned paths, inspect the full staged set, and run `node host/repository-safety.mjs --staged` before committing. The explicitly reviewed/frozen initial baseline manifest is the sole current cross-owner exception. Never stage the entire checkout or commit another active owner's changes.
7. Use `npm run repo:sync` only while the checkout/editor tasks are idle and clean, before work when safe and for periodic synchronization. It synchronizes existing commits with fast-forward updates only; it must not commit unfinished edits. Preserve the current agreed branch, never force-push/reset/stash, and report divergent history without automatically resolving it. Coordinate shared Git operations and honor publication freezes.

This is cooperative file ownership, not a filesystem lock. If the work starts requiring frequent edits to the same files, move to worktrees after a clean baseline is agreed.
